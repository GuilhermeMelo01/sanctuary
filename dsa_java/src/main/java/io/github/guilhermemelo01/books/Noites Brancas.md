**By Fyodor Dostoevsky**

##### Primeira Noite
```
Era uma noite maravilhosa, daquelas que só são possives quando somos jovens, querido leitor.
```
- Me peguei pensando sobre essa frase. Me fez pensar, como o Dostoevsky tem um percepção nostalgica da juventude, dizendo só ser capaz de uma noite daquelas existir, na **juventude**. Logo, querendo dizer que talvez não fosse o lugar o artefato **maravilhoso**, mas sim em que momento aquele lugar foi contemplado.
