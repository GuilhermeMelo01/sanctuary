Está relacionado à parte visual/interativa de um sistema: aquilo que o usuário vê e usa diretamente.

Exemplos de responsabilidades de **FED**:

- Criar telas, páginas e componentes visuais
- Trabalhar com **HTML, CSS, JavaScript**
- Usar frameworks como **React, Angular, Vue**
- Consumir APIs do backend
- Ajustar responsividade para desktop/mobile
- Melhorar experiência do usuário, acessibilidade e performance da interface.
