É um tipo de backend criado especificamente para atender um front-end ou canal específico.

`App Mobile  -> BFF Mobile  -> Serviços/APIs internas`
`Web Frontend -> BFF Web     -> Serviços/APIs internas`

A ideia é que o **BFF adapte os dados para a tela**, em vez de o front-end precisar chamar várias APIs e montar tudo sozinho.
