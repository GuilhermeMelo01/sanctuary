The "Ethernet" is used to connect all devices in a physical location.

#### **NIC -> Network Interface Card**
Nowadays the NIC comes with the motherboard on our computers.

#### **MAC -> Media Access Control Address**
Each computer has MAC to the connector in the NIC with a unique identifier
![[Pasted image 20260530190806.png]]

So, here we've two ports and each one will have a association with an unique identifier.

![[Pasted image 20260530191216.png]]
This physical address is the address of my computer (MAC)

![[Pasted image 20260530191547.png]]
If the MAC1 wants to **communicate** with the MAC3, it is going to send an envelope.
Inside of the envelope will be: **| DESTINATION MAC | SOURCE MAC | PAYLOAD |**
**Payload -> It's all the data inside of the envelope.**

QUICK REVIEW:
**LAN -> Local Area Network (Basically a physical location where we're connecting devices together)**
**Ethernet -> It's used to connect all LAN devices**
**Every NIC has a unique MAC address.**
